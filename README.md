🔥 Why Antonioilev Light Pack?
ComfyUI is incredibly powerful — but complex 3D workflows often require a lot of manual work, external tools, repetitive operations, and small utilities that are surprisingly difficult to build into a workflow.

Antonioilev Light Pack is built to remove that friction.

Instead of constantly switching between applications, repairing meshes manually, rebuilding UVs, checking textures, managing images, or writing small scripts for routine operations, you can perform many of these tasks directly inside ComfyUI workflows.

The Light Pack focuses on practical tools that are useful in real production workflows:

🧱 3D mesh processing and repair
📐 UV unwrapping and UV manipulation
🩺 Automatic mesh cleanup and fixing
🕳️ Hole detection and repair
🧷 Watertight and hard-weld operations
👁️ 3D, UV and PBR previews
🎨 Image processing
💾 Image and workflow state management
⚡ GPU-accelerated mesh operations
🧹 Memory and VRAM utilities
🎯 Projection and geometry tools
Everything is designed around one principle:

Solve real problems. Make the workflow faster. Keep everything inside ComfyUI.

📦 Installation
Clone this repository into your ComfyUI custom_nodes directory:

cd ComfyUI/custom_nodes

git clone https://github.com/Antonioilev/ComfyUI_Antonioilev_Lightpack.git
Restart ComfyUI after installation.

⚙️ Requirements
Antonioilev Light Pack is intended to run inside a standard ComfyUI environment.

Some nodes may use additional Python packages or external libraries depending on the functionality being used.

See the node documentation and installation instructions for the corresponding requirements.
